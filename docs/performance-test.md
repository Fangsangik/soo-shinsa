**테스트 목표**: SooShinsa 전체 시스템의 실제 성능 한계점 찾기  
**테스트 환경**: 로컬 개발 환경 (MacBook Pro M1)  
**애플리케이션**: Spring Boot 3.3.2 + MySQL 8.0 + Redis 7.0  
**테스트 도구**: Apache JMeter 5.6.3  
**테스트 기간**: 2025년 7월 8일  
**총 테스트 수**: 17개 시나리오 (50명~1000명)
